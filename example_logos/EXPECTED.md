# example_logos — test cases (public tier)

01–04 are invented stand-in logos generated by `tools/make_standins.py`. 05–10
are derived from them by `tools/make_synthetic.py`, which also derives
`test_images/synthetic/s09_display_p3_icc.jpeg` from 02.

To use other designs, replace 01–04 with files that keep the same numeric
prefixes and properties, then run
`.venv/bin/python tools/make_synthetic.py && .venv/bin/python tools/make_golden.py`.

Expected behavior refers to default settings unless a setting is named.

| File | Source | What it tests | Expected |
|---|---|---|---|
| 01_emblem_black_on_transparent.png | stand-in | Already-transparent input, round emblem, thin rings and small text | Removal skipped; circle fit by farthest pixel |
| 02_colored_on_white_srgb_icc.jpeg | stand-in | Colored logo, progressive JPEG with an embedded sRGB ICC profile, enclosed white fills (dots) | Background removed; dots become transparent (holes default), kept opaque with Keep holes |
| 03_dark_text_on_white.png | stand-in | Text logo with letter counters (P, A, R, O, &), distressed texture | Background and counters removed; with Keep holes counters stay opaque white |
| 04_red_on_offwhite_srgb_icc.jpeg | stand-in | Off-white (254) background, JPEG + ICC, wide layout, small details (registered mark, crown) | Background removed, no halo; small details preserved |
| 05_emblem_white_on_black.png | 01 inverted on black | Light logo on dark background | Contrast warning without invert; no warning with invert, logo black |
| 06_text_transparent_opaque_counters.png | 03 with outer background removed only | Known limitation: transparent input with opaque white counters | Removal skipped; counters stay opaque white |
| 07_colored_on_beige.jpeg | 02 on beige (240,228,205), JPEG q85 | Beige background, Lab tolerance, JPEG artifacts, white fills that are NOT the background color | Beige removed; white dots stay white (may get partial alpha: near-bg color) |
| 08_wordmark_gradient_bg.png | 04 on a vertical gradient | Non-uniform background | Must fail with a non-uniform border error (top and bottom edges differ) |
| 09_text_cropped_touching_edges.png | 03 cropped tight | Logo touching all four edges | Background removed; fit unaffected |
| 10_emblem_tiny_96px_on_white.png | 01 on white, 96 px wide | Tiny source: removal on few pixels + large Lanczos upscale | Works; output soft but correctly fitted |
